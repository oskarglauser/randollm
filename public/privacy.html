Privacy

randollm is a free service that returns random results to AI tools and to people calling its API. It’s built to know as little as possible about you.

What randollm receives

When your AI tool or your code calls randollm, it sends the tool name and its inputs, for example the range of a number or the list of options to choose from. randollm uses these to compute the result and returns it. Inputs and results are not stored.

There are no accounts, no API keys and no cookies. randollm doesn’t know who you are, and it never sees your conversation, only what the model sends to a tool.

Technical data and logs

randollm runs on Cloudflare Workers. Like any website, each request carries technical data such as your IP address, the time, the address requested and the name of your browser or AI client. randollm uses the IP address only in memory, to limit how many requests one client can make per minute.

Cloudflare keeps short-lived operational logs (request time, path, response status and similar) so problems can be found and fixed. They are kept for up to 7 days, then deleted automatically. Cloudflare’s own handling of this data is described in Cloudflare’s privacy policy.

Usage counts

To see how randollm is used, it counts each tool call anonymously: which tool, whether it came through MCP, the API or this website, the name your AI app or API client reports about itself (for example its app name and version), and the country Cloudflare sees the request coming from. No IP addresses and no inputs or results are counted. These counts are kept in Cloudflare Workers Analytics Engine for up to three months.

This website

This site uses Cloudflare Web Analytics, which counts page views without cookies and without tracking you across sites. The demos on the home page call the same API described above.

Signed receipts

Results can include a signature so that anyone can check a result wasn’t changed later. The signature is computed from the result itself. Nothing is stored to make this work.

Sharing

randollm doesn’t sell or share data with anyone. The only other party involved is Cloudflare, as the hosting provider.

Your choices

randollm keeps nothing that identifies you, only anonymous usage counts, so there’s nothing to look up, export or delete. To stop sending requests, remove randollm from your AI tool’s connectors or apps.
