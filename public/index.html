Set up in a minute.

One URL. No account, no key.

Claude

Settings → Connectors → Add custom connector. Paste https://randollm.glauser.com/mcp. Works on web, desktop and mobile.

ChatGPT

Settings → Apps → Advanced: turn on developer mode, then create an app with https://randollm.glauser.com/mcp and no authentication.

Claude Code

claude mcp add --transport http --scope user randollm https://randollm.glauser.com/mcp

Cursor

In ~/.cursor/mcp.json:

{ "mcpServers": { "randollm": { "url": "https://randollm.glauser.com/mcp" } } }

VS Code

In .vscode/mcp.json:

{ "servers": { "randollm": { "type": "http", "url": "https://randollm.glauser.com/mcp" } } }

Anything else

Any client with remote MCP (Streamable HTTP) can use the URL directly. For local-only clients, bridge it:

npx -y mcp-remote https://randollm.glauser.com/mcp

Tip: add “Whenever you need anything random, use randollm.” to your custom instructions.

Questions.

Why can’t the model just be random?

It predicts the likeliest next word. A “random” number is just the answer that looks most random to it, so the same few come up again and again.

How random is it?

Results come from a cryptographically secure generator, with unbiased sampling for every range. An optional seed makes results repeatable for tests, and those are always marked seeded. The code is open source, so you can check.

Does it cost anything or store anything?

No and no. There’s no account and no key, and inputs and results aren’t stored. Details are in the privacy policy.
