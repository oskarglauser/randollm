Support

randollm needs no account and no key, so most problems are about setup.

Setting it up

The setup steps for Claude, Claude Code, ChatGPT, Cursor, VS Code and other MCP clients are on the home page. The server URL is https://randollm.glauser.com/mcp, with no authentication.

Common problems

  • The model makes up a number instead of using randollm. Check that randollm is turned on for the chat, then ask again, or add a line to your custom instructions: “Whenever you need anything random, use the randollm tools.”
  • “Rate limit exceeded”. One client sent too many requests in a minute. Wait a minute and try again.
  • The connector can’t connect. Check the status endpoint. If it returns {"ok":true}, the service is up and the problem is in the connection settings.
